## RAMA (Lord Rama)

### Physical Description (Valmiki Ramayana, Book 1, Canto 1)
- **Height:** Tall and well-proportioned
- **Build:** Athletic, masculine
- **Complexion:** Dark blue (Shyama - like a dark cloud)
- **Eyes:** Large, lotus-like (Padma-chakshus)
- **Hair:** Black, curled
- **Features:** Handsome, graceful
- **Shoulders:** Broad, strong
- **Arms:** Long, reaching the knees (Janu-sparshi)
- **Chest:** Well-developed
- **Marks:** Has auspicious marks (lakshanas)

### Game Implementation
- **Base Color:** Dark blue (#1E3A8A)
- **Skin Tone:** Golden-brown undertones
- **Height Scale:** 1.0x (reference human)
- **Build:** Athletic, strong warrior
- **Equipment:** Blue/golden armor, bow

## HANUMAN (The Mighty Monkey)

### Physical Description (Valmiki Ramayana, Book 5, Sundara Kanda)
- **Species:** Monkey (Vanar) with divine powers
- **Height:** Variable (can grow/shrink) - normally 6-8 feet
- **Build:** Extremely muscular, powerful
- **Complexion:** Red/golden (Arun-varnam)
- **Face:** Monkey-like with fierce expression
- **Eyes:** Bright, intelligent
- **Tail:** Long, strong (often carried high)
- **Strength:** Superhuman (can lift mountains)
- **Speed:** Can move at speed of wind

### Game Implementation
- **Base Color:** Golden-red (#D4A574) with reddish tones
- **Complexion:** Warm golden-brown
- **Height Scale:** 1.1x (taller than humans, more powerful)
- **Build:** Extremely muscular
- **Features:** Monkey-like (prominent teeth, face), but humanoid body
- **Special:** Add tail, fierce expression

## RAVANA (Demon King)

### Physical Description (Valmiki Ramayana, Book 5, Sundara Kanda; Book 7, Uttara Kanda)
- **Height:** Extremely tall (100+ feet mentioned in texts)
- **Heads:** 10 heads (Dasha-mukha - literally "ten-faced")
- **Arms:** 20 arms (super-powerful)
- **Build:** Gigantic, muscular
- **Complexion:** Dark red/purple (demonic)
- **Features:** Fierce, terrible, with golden ornaments
- **Appearance:** Radiant with power but frightening
- **Presence:** Commands fear, royal bearing
- **Adornments:** Gold, jewels, crown

### Game Implementation
- **Base Color:** Dark red (#8B0000) with purple tones

- **Height Scale:** 3.0x (GIANT - can be slightly adjusted for gameplay)

- **Special Effects:** Dark aura, demonic presence
- **Equipment:** Golden ornaments, crown, weapons
